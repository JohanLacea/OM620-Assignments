# Graduate Supply Chain Analytics

This repository showcases my graduate coursework in supply chain analytics at California State University San Marcos. The projects use Python to prepare, analyze, and interpret date to support supply chain decisions.

## Inventory and Safety Stock Analysis

This project combines two assignments into one notebook. The first focuses on cleaning and organizing inventory data. The second builds on that work by calculating quantity statistics, average lead times, and safety-stock requirements.

## Accomplishments

The analysis connects data preparation with inventory planning. Quantity statistics describe transaction sizes and their variation, while lead-time information and safety-stock calculations support comparisons across service levels.

The combined notebook includes explanations, code, and results so readers can follow the preparation steps and calculations. References to supporting resources are included in the notebook.

## Repository Organization

The project files are organized as follows:


The `data` folder contains two supporting datasets. The metadata provides reference information about the items being analyzed. The transaction data records inventory activity over time. Together, these datasets support identifying relevant items, summarizing quantities and lead times, and calculating safety stock.
